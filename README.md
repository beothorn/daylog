# Daylog

A tiny tray app to log what you are doing, so you can remember what you did yesterday.

Click the tray icon (a small book), type a few words and pick a task, and Daylog appends a timestamped markdown entry to your diary file.
Single jar, no install, everything stays on your machine, instant to open. Works on Windows and Linux.

## Why
You keep a plain-text diary and want zero-friction entries: autocomplete from past tasks, the last task prefilled,
multi-line notes, and your existing file is only ever appended to.

## Use
Download `daylog.jar` from the [releases page](https://github.com/Beothorn/daylog/releases) (or build it with `mvn verify`), then:

```bash
java -jar daylog.jar
```

Full guide: [Docs_user/usage.md](Docs_user/usage.md). Developers: see [AGENTS.md](AGENTS.md) and [Docs_technical](Docs_technical).
