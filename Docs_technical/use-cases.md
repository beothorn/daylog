# Use cases

## Log what I am doing
I run the jar; an icon appears in the tray. I click it; a dialog shows a one-line task field, already filled with my last task,
and below a 4-line text box (scrollbar when I write more). I write a sentence or a paragraph and confirm. A line is appended to my log file:
the timestamp, the task in backticks, then my text in a fenced block.

## Pick the task fast
I type "Off" and the field completes to "Offhour work" from earlier entries. I press Tab/End or just keep typing.

## Choose where to log
I keep a diary folder with one file per day (`01.md`, `02.md`...). I right click the tray icon, choose "Choose log file", and a file
explorer opens in the folder of the previously chosen file. I pick today's file; new entries are appended to it, existing content is kept.

## Remember yesterday
Next day I open the diary file and read what I did, in order, with times.

## Out of scope
Time totals, reports, sync, accounts, editing past entries, network.
